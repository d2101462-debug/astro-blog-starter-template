# Editable fictional landing page

Open `admin.html` to edit the organization name, subtitle, headline, description, logo letter, and footer. Changes are stored in the browser's localStorage and are reflected when `index.html` is opened in the same browser.

For a real multi-user admin system, the editor should be moved behind authentication and backed by a database/server. Do not use it to impersonate a real government/financial institution or collect sensitive credentials.
